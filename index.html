Tools Box

Мои приложения в одном месте. Сними инструмент со стены: откроется описание, веб-версия и APK для Android. Бесплатно и без рекламы.

Tools Box · версии и APK берутся из релизов GitHub · данные приложений хранятся на твоём устройстве

О проекте

Tools Box — витрина моих приложений. Каждое висит на стене мастерской, как инструмент на своём крючке.

Как пользоваться

  • Нажми на инструмент — внизу появится описание приложения.
  • «Открыть» запускает веб-версию прямо в браузере, «Скачать APK» — последнюю версию для Android с GitHub.
  • Пунктирный контур на стене — место для следующего приложения.
  • «Установить» добавит Tools Box на главный экран.

Установка APK на Android

  • Скачай APK и открой его из уведомления или папки «Загрузки».
  • Если телефон спросит — разреши установку из этого источника.
